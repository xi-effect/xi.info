## Зачем это может понадобиться

Иногда браузер подгружает не самую свежую версию страницы, поэтому после обновлений могут появляться устаревшие экраны или странные ошибки. При этом в режиме инкогнито всё может быть в порядке.

Чтобы решить эту проблему, обновите сохранённые данные для нашего сайта.

Откройте ту страницу sovlium, где замечаете проблему. Чаще всего это **[app.sovlium.ru](https://app.sovlium.ru)** — дальнейшие шаги делайте **на этой вкладке**.

## Chrome, Яндекс Браузер, Edge и другие на том же движке

Названия кнопок могут быть на русском или английском — ориентируйтесь на смысл.

1. Убедитесь, что открыта вкладка с sovlium.
2. Откройте панель разработчика одним из способов:
   - нажмите клавишу **F12**
   - нажмите сочетание **Ctrl+Shift+I** (Windows) / **Cmd+Option+I** (Mac).
3. Вверху панели найдите вкладку **Приложение** — по-английски часто пишут **Application**.
4. Слева откройте раздел **Хранилище** (**Storage**) или нажмите на строку с адресом сайта в списке.
5. Нажмите кнопку **Очистить данные сайта** (**Clear site data**).
6. Если браузер спросит подтверждение — согласитесь.
7. Закройте панель (крестик или снова **F12**).
8. Обновите страницу кнопкой обновления или клавишей **F5**.

Готово: загрузится актуальная версия sovlium, данные для других сайтов не изменятся.

## Firefox

1. Откройте нужную вкладку sovlium.
2. Нажмите **F12** или **Ctrl+Shift+I** / **Cmd+Option+I**.
3. Откройте вкладку **Хранилище** (**Storage**) — в некоторых версиях она может называться **Приложение** (**Application**).
4. Слева выберите сайт в списке.
5. Удалите все данные для этого сайта кнопкой **«Удалить всё»** / **Delete all** — формулировка может чуть отличаться.

Затем обновите страницу. При необходимости войдите в аккаунт снова.

## Safari на Mac

1. Включите меню **Разработка**: **Safari** → **Настройки** → **Дополнения** → поставьте галочку **Показывать меню «Разработка»**.
2. Откройте наш сайт в Safari, затем **Разработка** → **Показать веб-инспектор** (или **Cmd+Option+I**).
3. Найдите раздел про **данные сайта** / **хранилище** для текущей страницы и очистите данные для этого сайта.

Если такой кнопки не видно, в меню **Разработка** найдите опцию **Общая очистка сохранённых файлов** — она действует на **весь Safari**, не только на наш сайт. Пользуйтесь ей, если другого варианта нет.

## Телефон или планшет

Там обычно нет такой же панели, как на компьютере. Если проблема только на телефоне, попробуйте в настройках браузера очистить данные только для sovlium или обратитесь в поддержку — подскажем, что удобнее в вашем случае.

---

## Особенности

После очистки данных браузер заново загрузит страницу с сервера. Возможно, придётся войти в аккаунт ещё раз — это нормально: вместе с устаревшими файлами сбрасываются и данные для входа.

## Если ничего не помогло

Напишите в **поддержку** и при необходимости приложите [технический отчёт](../profile-settings/support-tech-report) из личного кабинета — так мы быстрее разберёмся.
