# Кандидатные пользовательские сценарии для проверки

> Это **не спецификация** текущего приложения. Перед описанием в статье каждый шаг и существование функции необходимо проверить в Playwright; при необходимости заглянуть в `../xi.tutor`.

| ID  | Приоритет | Роль               | Конкретная задача                               | Обязательная проверка                                                                                           |
| --- | --------- | ------------------ | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| J01 | P0        | Репетитор          | Войти и понять, с чего начать работу            | Реальный путь с текущего экрана, первый экран после входа                                                       |
| J02 | P0        | Репетитор → ученик | Пригласить ученика к работе                     | Создание/получение приглашения, фактический приём под аккаунтом ученика, конечный доступ                        |
| J03 | P0        | Репетитор          | Подготовить кабинет и материалы к первому уроку | Реальные кнопки, создание/выбор доски, видимость ученику                                                        |
| J04 | P0        | Репетитор → ученик | Провести первое занятие                         | Путь до запуска и присоединения, разрешения/ошибки, UI каждой роли                                              |
| J05 | P0        | Ученик             | Открыть материалы после занятия                 | Условия видимости доски/файлов, что доступно без текущего урока                                                 |
| J06 | P0        | Обе роли           | Решить проблему со входом, звуком или видео     | Реальные сообщения интерфейса, разрешения браузера; не имитировать неисправности искусственно без необходимости |
| J07 | P1        | Репетитор          | Запланировать урок и изменить его               | Разовый/повторяющийся сценарии, перенос/отмена — только безопасные тестовые действия                            |
| J08 | P1        | Репетитор → ученик | Выдать или получить домашнее задание            | Сначала подтвердить наличие и доступность функции, не описывать будущую реализацию как действующую              |
| J09 | P1        | Репетитор → ученик | Загрузить и показать файл                       | Реальный upload, права доступа, ограничения; только маленький нейтральный тестовый файл                         |
| J10 | P1        | Репетитор          | Посмотреть счета, оплаты и подписку             | Только read-only UI; **не** выполнять реальные оплаты или списания                                              |
| J11 | P1        | Обе роли           | Настроить профиль, уведомления и устройства     | Доступные меню, отличие ролей и платформ                                                                        |
| J12 | P2        | Обе роли           | Работать на мобильном устройстве                | Действительный мобильный viewport, расположение и доступность элементов                                         |

Для каждого сценария разделяй: **что видно и проверено**, **что найдено только в коде**, **что невозможно проверить в этих аккаунтах**. При несогласованности — зафиксируй её как проблему продукта, а не «исправляй» текстом документации.
